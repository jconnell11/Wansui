__Notes:__
* The replacement SD card speeds up the Jetson Nano substantially (it's a bit of a dog otherwise).
* The alternate internal battery pack noticeably extends the runtime of the robot (but requires some soldering).
* The circular array microphone allows the robot to find the direction of the speaker (semi-reliably).
